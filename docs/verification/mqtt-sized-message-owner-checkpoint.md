## 实际修改与不变量

入站 owner 改为私有元数据加可变长度载荷。首片声明的总载荷长度通过 0–4096 字节边界后才驱动申请；分片过程中不扩容、不复用该 owner，续片声明增减均拒绝，释放始终使用原有精确长度。接收完成后将 owner 移交原三槽通知队列；第四条在途仍可临时持有存储，完成时没有空槽仍按原合同关闭会话。

公开 `emqtt_message_t`、`emqtt_receiver_t`、`emqtt_event_t` 及函数签名保持。固定公开接收入口和可变长度 owner 使用同一个私有分片校验核心；官方 MQTT 编解码、outbox、队列容量、最大合法输入与出站、证书和可信时间策略未改。`poll` 继续返回完整值拷贝，Topic 与载荷未用尾部保持为零。畸形片、断线、通知队列失败、主动停止和销毁在原 SDK 回调收敛条件下清零整个实际申请并释放；原 stop/destroy 失败保留 owner 的合同保持。

官方 GCC 15.2.0 使用两个实际 SDK 工程的完整编译参数生成独立 ABI 探针，仅对探针关闭 LTO；两个目标均确认如下尺寸：

| 对象 | 字节 |
| --- | ---: |
| 原公开固定消息 | 4368 |
| 私有可变 owner 元数据 | 272 |
| 满长 4096 字节载荷的 owner | 4368 |
| runtime | 2416 |
| 公开 receiver | 12 |

申请为 `272 + 实际载荷长度`，零载荷为 272 字节，1 字节载荷为 273 字节；满长仍为 4368 字节。未改变三条满长排队加第四条满长在途的合法峰值。单条小消息的局部差值不等于整机 OTA 历史堆增量，不能用于宣布 48 KiB 门通过。
